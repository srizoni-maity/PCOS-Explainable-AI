Data Availability :

The participant-level survey dataset used in this study is not publicly available in this repository because it contains participant-level information and is subject to applicable privacy and data-sharing restrictions. The dataset used for the analysis is available from the corresponding author upon reasonable request, subject to approval and any applicable privacy or data-sharing requirements.

The public repository provides the analysis code, configuration files, and non-participant-level computational outputs necessary to document the analytical workflow and reported results.
